# Mazhar AI Lab

A professional AI engineering portfolio monorepo for **Mazhar Jahjah (AI & Data Engineer)**, showcasing production-grade projects in computer vision, data pipelines, LLM systems, backend APIs, and deployment.

## Overview
This lab is organized as a set of independent, reproducible projects with shared engineering standards: modular architecture, clean code, environment configuration, Docker support, tests, example data, and example API requests.

## Projects

| Project | Focus | Stack | Demo |
|---|---|---|---|
| `ai-id-verification` | ID document extraction (CV + OCR) | FastAPI, OpenCV, PyTorch, Tesseract, Gradio | See project README |
| `ai-data-pipeline` | Streaming AI data pipeline | Apache Beam, Dataflow, BigQuery | See project README |
| `rag-document-assistant` | Retrieval-augmented QA | LangChain, FAISS, OpenAI API, Streamlit | See project README |
| `travel-ai-recommender` | Personalized travel recommendations | Django, scikit-learn, PostgreSQL | See project README |
| `portfolio-site` | Static portfolio website | HTML, CSS, JS | GitHub Pages |
